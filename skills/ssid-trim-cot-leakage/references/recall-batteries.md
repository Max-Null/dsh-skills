# 探针

针对[分类法](../SKILL.md#分类法)的探针。**每一个命中都需要语义判断**——探针按设计**会过度匹配**，而按本性又**匹配不足**：每一轮评审都会发现没有探针能抓到的案例。所以它们必须配一次**无模式的最密行文阅读**。

## 调用规则

- 加 `--hidden --glob '!.git/**'` 才能搜到点目录。
- **排除项写在最后**，免得后面的包含项又把它们放回来：`--glob '!vendor/**' --glob '!node_modules/**' --glob '!references/**'`，再加上 scope 内的派生物目录。**本 skill 自己的文件会引用泄漏措辞作校准**——判断它们时应视作证据，不是使用。
- 中文行文直接匹配；英文行文加 `-i`，让句首大写也能命中（`This PR adds…`、`Probably fine…`）。
- **绑定完整短语**：`\bthis PR\b` 要匹配 `this PR adds`，而不匹配 `this project`、`this process`、`this provider`。
- **一个零命中的模式什么都证明不了，直到它命中一个已知正例；一个嘈杂的模式什么都证明不了，直到它拒绝一个近失负例。** 两者都要先校准，再相信语料结果。

## 中文探针（主探针集）

```sh
# 变更叙事与版本戳
rg -n --hidden '第一版|本版|旧版|老的|曾经|原来|不再|以前|之前是|改成了|已改为|换成了'

# 评审编排与面向评审者的辩解
rg -n --hidden '评审|上一轮|本轮修正|按评审意见|评审要求|二次审查|被拒绝'

# 模糊措辞与规划残留
rg -n --hidden '大概|应该够了|暂时|先这样|凑合|回头再说|待定'

# 指示性戳记（比上面几组更易误报，务必逐条判断）
rg -n --hidden '本轮|本次|今天|现在|新的'
```

## 英文探针（保留）

```sh
rg -n --hidden -i '\bthis PR\b|\bthis branch\b|\bprevious commits?\b|\bused to\b|\bno longer\b|\bpreviously\b|rejected in review|\bfor now\b'
```

## 已知假阳性家族

下列都是**判断后保留**的，**预期还会出现**：

- **"旧版/新版"指交付物版本而非仓库历史** —— "老用户安装 v0.1.13：启动时版本指纹不一致"讲的是**安装场景**，不是代码变更史。
- **release notes 与决策记录里的变更叙事** —— 那是**内容本体**（五个合法主场之一）。
- **"不再"作为产品行为** —— "点击导航条不再报错"陈述的是**修复后的当前行为**；它的泄漏版本是"（相对某个未提交的版本）不再报错"。
- **运行时的新旧状态** —— "旧连接在新连接接受之前排空"是生命周期，不是历史。
- **`§N` 有已提交属主** —— 外部标准与拥有自己 § 编号的已提交文档仍可按节引用。
- **"实测"** —— 出处词是承重的；"(实测：512 层嵌套 ≈ 0.15 s)"保留。
- **反事实现在时** —— "没有 X 时会发生 Y"是回归钉，保留。
- **`proxy.` 之类的代码 token** —— "确认无未处理的 `proxy.` 引用"里的 token 是规范名，不是变更叙事；泄漏的是"都不再有"这个比较级。
